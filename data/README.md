# Data files

## Real Volve workbook

`Volve production data.xlsx` is the real production workbook copied into this project from the Equinor Volve data release. It contains daily and monthly production sheets. The official release page and terms are linked in the project README. Give Equinor and the former Volve license partners attribution when sharing project results, and do not imply their endorsement.

## Synthetic demo data

`synthetic_production_demo.csv` is generated illustrative data for trying the VolveWatch interface. It is not from the Volve field, does not represent any real well, and must not be used as project evidence or reported as a real production result.

It contains four invented well IDs across 36 monthly periods. It includes a deliberate production spike and two malformed rows so the charts, forecast, anomaly flags, and import quality counts can be explored. Its rate column names include example units solely to demonstrate column mapping.
